Keyboard shortcuts

Ctrl / ⌘ + Z Undo the last draft action — the same as the Undo button. Holding the keys does not unwind several picks.
N Nomination recommendations — refreshes the nomination panel only, so it is safe to press mid-bid: the player, price and bidder toggles survive it.

Both are ignored while you are typing in a text box, a number box or a dropdown — so a name containing "n" types normally, and Ctrl+Z in a field undoes your typing rather than the last pick. Click a bidder logo and focus lands on a button, not a field, where N is live again.

Everything else is a click. Esc closes this.
